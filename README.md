# 🌦️ React Weather App

A modern and responsive weather application built with **React + Vite** that provides real-time weather information, hourly forecasts, and daily forecasts based on the user's current location or searched city. The application fetches live weather data using a weather API and presents it through a clean and intuitive user interface.

## 🚀 Live Demo

🔗 **Live Website:** https://react-weather-app-one-xi.vercel.app/

---

## ✨ Features

* 📍 Automatic weather detection using geolocation
* 🔍 Search weather by city name
* 🌡️ Current temperature and weather conditions
* 🕒 Hourly weather forecast
* 📅 Daily weather forecast
* 💧 Humidity information
* 💨 Wind speed details
* 🌙 Dynamic day/night weather icons
* 📱 Fully responsive design
* ⚡ Fast loading with Vite

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Mayanksharma3012/react-weather-app.git
```

Navigate to the project:

```bash
cd react-weather-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
